# Elevator Saga Solution

My final solution to the Elevator Saga game, as featured in my video.

## Video

[Watch the video on YouTube](https://youtu.be/yCh_G051S4U)

## About

Elevator Saga is a game where you write JavaScript code to control
elevators and try to transport passengers as efficiently
as possible.

This repository contains the final solution I developed during the
challenge shown in the video.

## Solution

The complete code is available in [`solution.js`](./solution.js).

The solution uses separate waiting lists for the elevators and
redirects requests to another elevator when the assigned elevator
is too busy.

## Note

This is the final code I ended up with during the challenge. It is
not intended to be a perfect or best-practice JavaScript solution.
It is simply the solution I developed for the video.

There are definitely things I would do differently if I were to
write it again today.
